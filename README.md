# Resident Evil 4 · AI Rescue Simulator


## Open the simulator

▶ [Launch AI Rescue Simulator](https://milan-keldybekov.github.io/AI-fundamentals-final/)

Opens directly in your browser. No download or installation required.

📊 [View the presentation](./PRESENTATION/)



## Project layout

- `index.html` — page structure and entry point
- `css/styles.css` — styles and animations
- `js/app.js` — simulator logic, controls, and media playback
- `assets/images/` — logo and character artwork
- `assets/audio/` — four soundtrack tracks
- `assets/video/intro.mp4` — original introduction video, including its music
- `assets/video/intro.webm` — VP8/Vorbis version with the same video and music



## Intro playback

The intro offers WebM and MP4 sources for browser compatibility. The site opens on a black screen with a Start intro button. Activate the button to start the video and its embedded music together; click or press a key during playback to fade into the simulator. Input while the video is loading does not skip it. If neither format can play, the continue button still opens the simulator.
